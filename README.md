A Node 22 program that writes the funniest possible last words a phone
could say as its battery hits 1 percent — one single line, to
`/output/entry.txt`.

The phone spends its final 1% not on a goodbye, but on one last judgmental
truth: telling its owner their screen time was 11 hours today.

## Run

```sh
node main.ts
cat /output/entry.txt
```

Deterministic: every run writes the exact same line — no clock, no
randomness, no network, no input.
